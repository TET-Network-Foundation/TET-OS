The TET test network is offline

The company that hosted our servers closed the account after a payment was late. The servers and everything stored on them are gone: the test chain, and the files and messages it held. Nothing on them can be brought back.

What still works

A signature made earlier still checks offline. Keep your .sig.json file and the file it signs, and open them in the offline verifier: it needs no network and no TET server. It shows which key signed, and that the file is exactly the one that was signed. It doesn't show who holds the key.

What can no longer be checked

A record that says it existed before block N of the old test chain can no longer be checked against a live node: no node serves that chain any more. The signature itself still checks; the block it names can't be looked up.

What comes next

A new test chain is planned. It will have its own name and its own genesis, so a record made for the old chain can't be mistaken for one on the new chain. Your 12 words still make the same key: keep them.

TET のテストネットワークは停止しています

サーバーを預けていた会社が、支払いの遅れを理由にアカウントを閉じました。サーバーと、そこに保存されていたものはすべて失われました。テストチェーンと、そこにあったファイルやメッセージです。サーバー上のものは元に戻せません。

今も使えること

以前に付けた署名は、今もオフラインで確かめられます。.sig.json ファイルと、署名した元のファイルを手元に残し、オフライン検証ツールで開いてください。ネットワークも TET のサーバーも要りません。どの鍵が署名したか、そしてファイルが署名されたものとちょうど同じかを示します。鍵を誰が持っているかは示しません。

もう確かめられないこと

古いテストチェーンの「ブロック N より前にあった」という記録は、もう動いているノードで確かめることができません。そのチェーンを配信するノードがもうないからです。署名そのものは今も確かめられますが、記録が指すブロックは調べられません。

これから

新しいテストチェーンを計画しています。名前もジェネシスも新しくなるので、古いチェーンの記録が新しいチェーンのものと取り違えられることはありません。あなたの 12 語からは今も同じ鍵ができます。大切に保管してください。
