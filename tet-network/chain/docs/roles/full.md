# Role: full

## 目的

最終化には参加しつつ、（validator ほどの権限は持たない形で）ブロック/状態を保持する。

## 必要ポート（例）

- P2P: `30333`
- RPC (JSON-RPC): `9933/9944`
- Prometheus: node 設定に準ずる

## 必須フラグ（最小）

- `--chain tet_testnet`
- `--no-granpa` を使わない（運用要件に応じて GRANDPA observer を有効化）
- Keystore を載せるかどうかは「作者権限が必要か」で決める

## 永続データ/バックアップ

- プルーニングは必要に応じて無効化/有効化
- スナップショット+復元手順を定期実施
