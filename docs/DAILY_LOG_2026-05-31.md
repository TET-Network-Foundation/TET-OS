### Tmail Step 3: UI Messages tab + TS E2EE library (commit 1d3173f)

CRITICAL DESIGN CORRECTION:
Task prompt stated 'pqcrypto_kyber::kyber768 = ML-KEM-768'. Cursor caught
this as factually wrong. pqcrypto-kyber (used by backend e2ee.rs) is
CRYSTALS-Kyber Round-3, byte-incompatible with FIPS-203 ML-KEM-768.
TS side uses crystals-kyber-js@^1 (Round-3) to maintain byte-level interop.

Future hardening: migrate BOTH sides to FIPS-203 ML-KEM-768 (separate task).
Whitepaper should qualify Phase 0 claims accordingly.
