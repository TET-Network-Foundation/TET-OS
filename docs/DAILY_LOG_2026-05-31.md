## Lessons

- UI 単独動作確認では bug を見逃す。Phase 0 ship 前に end-to-end test (UI -> tet-core -> gossip -> 他 node balance) が必須。
- Off-chain mutation は L1 設計の根本欠陥。/wallet/transfer と initial_airdrop の両方が同じ pattern で consensus 素通りしてた = 設計時の暗黙の前提に latent risk があった。
- Cursor の forensic で path trace を file:line で詳細に追えば、深い consensus bug も 25 分で root cause 特定できる。
- 1 つの fix (Send Coins) が他の latent bug (mine_pending_block_as の duplicate tx 問題) を副次的に潰した。Defensive design の連鎖効果。
