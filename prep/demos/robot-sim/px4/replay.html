Why TET fits this

The flight log reaches an inspector or a client through hands that do not hold the aircraft's key: the pilot's laptop, an upload, an email. The signing key is pinned once; every later copy can be checked offline against it.

What changes with a signed log

The ULog file stays standard and opens in the usual tools. Beside it, one signed record per chunk (about one second of log time) holds the hash of that chunk's bytes. An altitude lowered under the ceiling, or a fence exit moved back inside, is refused on the chunk that held it.

How this differs from what exists

PX4 can encrypt its log (XChaCha20, key wrapped with RSA-2048): that keeps the log secret from whoever lacks the private key; it does not let a third party check who wrote it. MAVLink signing protects the radio link, not the stored file (both from PX4's own documentation in its source tree). Signing is the other way round: the log stays readable by anyone, and anyone holding the pin can check which key signed each chunk. The two can be combined; this demo does not encrypt.

What this does not show
  • That anything flew: this is a simulation; no flight happened. In the PX4 run, PX4 flew a simulated vehicle (its built-in SIH simulator) on this computer.
  • That PX4 wrote the log: the check judges that these bytes are the signed ones, not who wrote them.
  • That the autopilot signed it: the chunks were signed after the flight, on the same computer, by the notebook tool. Signing inside PX4 while it flies is not built.
  • That the vehicle kept to the ceiling or the fence: they are this demo's lines, drawn and checked against the log afterwards. In the PX4 run, PX4's own geofence was not set, and the mission flew past both on purpose.
  • Which machine signed: the check judges which key signed each chunk; it does not judge which machine or person held that key.
  • That a sensor told the truth: the log holds what was measured (here, simulated).
  • That the log is complete at its end: the check does not judge whether the last chunks are present.
  • When a chunk was written: the check judges which key signed each chunk; it does not judge when the signing happened.
